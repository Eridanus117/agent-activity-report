## 与批准计划的一处偏离

计划写「按每个文件最早记录的时间排序」。实现时核实发现，被复制的记录保留原时间戳，两个文件的最早时间相同，单靠这一条分不出原件。实现改为：先比最早记录时间，相同时比文件修改时间。依据是本机唯一一对互相复制的文件（原件的修改时间较早），样本只有一个。已写入 SDD「按天筛选与去重」，标为待审。
